# `lib/user/` — Member flows

Presentation and domain logic for **members** (not leader-only moderation).

| Module | Purpose |
|--------|---------|
| `home` | My / joined project lists |
| `discover` | Search, filter, join |
| `contributions`, `contribute` | Contribute flow |
| `borrow` | Borrow request & repay |
| `vff` | Friends & family hub |
| `investment`, `project_detail` | Member investment & vote UI |
| `create_project_member_fund` | UI-only vacation/emergency walkthrough |

Shared APIs and detail shell → `lib/features/`.

See [FEATURE_MAP.md](../../FEATURE_MAP.md).
